# User Stories - Finances SaaS

## Módulo: Dashboard

### US01 - Visualizar Dashboard Financeiro
**Como** usuário do sistema  
**Eu quero** acessar um dashboard com estatísticas financeiras  
**Para que** eu possa ter uma visão consolidada da minha situação financeira

**Critérios de Aceitação:**
- O dashboard deve exibir o total de despesas avulsas do período
- O dashboard deve exibir o total de despesas recorrentes
- O dashboard deve exibir uma lista dos últimos gastos registrados
- Os valores devem ser atualizados em tempo real conforme os dados são alterados
- Deve ser possível filtrar por período (mês corrente, personalizado)

## Módulo: Despesas Avulsas

### US02 - Cadastrar Despesa Avulsa
**Como** usuário do sistema  
**Eu quero** cadastrar uma despesa avulsa com nome, observações, preço, data e categoria  
**Para que** eu possa registrar gastos pontuais e não recorrentes

### US03 - Listar Despesas Avulsas
**Como** usuário do sistema  
**Eu quero** visualizar a lista de despesas avulsas cadastradas  
**Para que** eu possa consultar meus gastos pontuais

### US04 - Editar Despesa Avulsa
**Como** usuário do sistema  
**Eu quero** editar os dados de uma despesa avulsa existente  
**Para que** eu possa corrigir ou atualizar informações do gasto

### US05 - Excluir Despesa Avulsa
**Como** usuário do sistema  
**Eu quero** excluir uma despesa avulsa  
**Para que** eu possa remover lançamentos incorretos ou indevidos

### US06 - Visualizar Total de Despesas Avulsas
**Como** usuário do sistema  
**Eu quero** ver o valor total de todas as despesas avulsas na página de listagem  
**Para que** eu tenha um resumo rápido do valor total de gastos pontuais
